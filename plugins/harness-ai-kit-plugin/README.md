# harness-ai-kit-plugin

harness-ai-kit 的 dsh 宿主插件（plugin 资产类型第一个实例，宿主 dsh）。

- 工具：`harness-ai-kit`（list / search / info / install / doctor）
- 随包技能：`harness-ai-kit-ops`（精简版操作手册，`ctx.skills.register` source: bundled）
- 纯 JS + Markdown，无构建/无 prepare 脚本；`dsh plugin add` 一次到位。

详细用法见 [USAGE.md](./USAGE.md)。
