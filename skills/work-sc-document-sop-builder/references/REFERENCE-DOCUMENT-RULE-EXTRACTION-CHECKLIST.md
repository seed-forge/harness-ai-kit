# 文档规则提取清单

用于从参考 `docx / md / pdf / 历史成品` 中反向提取规则，并沉淀为可复用 SOP。

## 一、参考源确认

- [ ] 参考材料是什么格式：`docx / md / pdf / 其他`
- [ ] 是否需要先转成 `md`
- [ ] 这是单份成品，还是系列模板中的一份
- [ ] 该参考文档属于哪一类文档
- [ ] 后续是否会重复编制同类文档

## 二、结构规则

- [ ] 有哪些一级章节
- [ ] 一级章节顺序是否固定
- [ ] 是否存在固定二级章节
- [ ] 是否存在固定附录、表格、附件、页眉页脚结构
- [ ] 哪些章节是必须项
- [ ] 哪些章节是可选项
- [ ] 哪些章节只能简写，哪些必须展开

## 三、内容规则

- [ ] 每一章要求写什么
- [ ] 每一章不应写什么
- [ ] 是否存在固定要素清单
- [ ] 是否要求写背景、问题、方案、效果、边界
- [ ] 是否要求写输入、处理、输出、异常
- [ ] 是否存在必须回应的审稿点或客户关注点
- [ ] 哪些内容属于主线，哪些属于补充说明

## 四、表达规则

- [ ] 整体语气是技术型、公文型、汇报型还是宣传型
- [ ] 是否存在固定标题口径
- [ ] 是否存在固定副标题
- [ ] 是否存在固定称呼、固定句式、固定衔接语
- [ ] 哪些表达应避免
- [ ] 是否要求去 AI 味、去营销味、去模板腔
- [ ] 是否要求中文优先、英文缩写首处解释

## 五、版式规则

- [ ] 页面边距
- [ ] 标题字体、字号、对齐方式
- [ ] 副标题字体、字号、对齐方式
- [ ] 一级标题规则
- [ ] 二级标题规则
- [ ] 正文字体、字号、行距、缩进
- [ ] 列表段落规则
- [ ] 表格样式规则
- [ ] 首页信息栏是否固定存在
- [ ] 页眉页脚、页码是否有固定要求

## 六、模板与数据结构规则

- [ ] 是否存在固定信息栏字段
- [ ] 是否存在固定表头或字段名
- [ ] 是否存在固定编号规则
- [ ] 是否存在固定状态栏、签字栏、备注栏
- [ ] 是否需要抽成模板字段
- [ ] 是否需要抽成 profile

## 七、导出规则

- [ ] 最终输出格式是什么
- [ ] 是否区分多个导出 profile
- [ ] 文件名是否允许带版本号
- [ ] 标题区是否允许显示版本号
- [ ] frontmatter 是否需要忽略
- [ ] markdown 标题层级如何映射到导出文档
- [ ] 导出后需要检查哪些版式项

## 八、工作流规则

- [ ] 是否永远先改 `md` 再导出
- [ ] 是先确认结构还是先确认格式
- [ ] 内容确认后才允许导出吗
- [ ] 是否需要预审版、中间版、正式版分层
- [ ] 是否要把“修改建议”和“正文内容”分离
- [ ] 是否需要和其他专业 Skill 协同

## 九、显性要求与隐性要求区分

- [ ] 哪些规则来自原文明确说明
- [ ] 哪些规则来自成品分析归纳
- [ ] 哪些规则只是当前项目约定
- [ ] 哪些规则可推广到其他同类文档
- [ ] 哪些规则不宜泛化

## 十、沉淀输出

至少确认要不要生成以下资产：

- [ ] `章节编写要求.md`
- [ ] `导出模板与格式要求.md`
- [ ] `编制工作流.md`
- [ ] 项目级 `SKILL.md`
- [ ] Skill 卡片
- [ ] 收藏库索引

## 十一、最终判断

完成提取后，应能明确回答：

1. 这个参考文档要求“写什么”了吗
2. 这个参考文档要求“怎么写”了吗
3. 这个参考文档要求“怎么排版”了吗
4. 这些规则是否已经变成可复用 SOP
5. 后续其他文档编制是否可以直接参照
