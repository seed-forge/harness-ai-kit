# REFERENCE: 截图与命名规范

> 本规范给出默认值；具体项目可在实战中校准后回写（标记"待项目实战校准"的项优先）。

## 视口与尺寸

- 默认固定视口 `1920×1080`，保证同一手册截图尺寸一致、排版整齐
- 若目标系统在小屏下才暴露某些交互（如移动端菜单），单独记录该步的视口，并在台账 notes 注明
- 截图默认 PNG（无损、支持透明），不用 JPG（避免文字模糊）

## 命名

- 文件名：`<step_id>-<页面名>.png`，如 `02-工单列表.png`
- `step_id` 与 capture-ledger / capture-trace 中一致（关联键）
- 页面名用系统界面真实名称，避免自造名词
- 每条流程独立子目录：`captures/<flow>/`

## 截图内容规则

- 一张截图只服务一个主说明目标；信息过密时拆成多张或局部放大
- 优先整页截图；仅当页面很长且关键区域集中时用区域截图，并在 notes 说明截取范围
- 关键操作点（要点击的按钮/要填的字段）可加**点击位置标注**（红框/序号），标注不遮挡关键文字
- 截图应反映"操作后的结果态"或"即将操作的状态"，与该步文字描述的时刻对应

## 标注（可选）

- 点击位置：红色矩形框 + 可选序号
- 输入示例：在字段旁标注示例值（脱敏后）
- 标注是增强，不是必需；B 阶段以真实截图为主，标注可在成稿阶段补

## 待项目实战校准项

- 视口尺寸是否需按系统实际调整
- 是否需要统一深/浅色主题
- 标注风格（颜色、粗细、字号）
- 长表单/长列表的截图切分粒度
