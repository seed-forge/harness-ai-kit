# 社区官方能力引用清单

> 原则：只引用不重写。以下为 web 工程化常用官方/社区能力入口。

## 脚手架（官方）

| 工具 | 用途 | 入口 |
|------|------|------|
| create-vue | Vue3 + Vite + TS 官方脚手架 | `npm create vue@latest` |
| create-vite | 框架无关 Vite 模板 | `npm create vite@latest` |
| create-next-app | Next.js 官方脚手架 | `npx create-next-app@latest` |
| Angular CLI | Angular 官方 | `npm i -g @angular/cli` |

## 构建工具

- Vite：https://vite.dev/guide/ （官方文档）
- Webpack：https://webpack.js.org/ 
- Turborepo：https://turborepo.com/ （monorepo 构建缓存）

## 包管理器

- pnpm：https://pnpm.io/ （monorepo 推荐）
- npm / yarn：官方文档

## 代码质量

- ESLint / Prettier / Stylelint：官方文档 + eslint-plugin-vue flat config

## 微前端

- qiankun：https://qiankun.umijs.org/
- micro-app：https://micro-zoe.github.io/micro-app/
