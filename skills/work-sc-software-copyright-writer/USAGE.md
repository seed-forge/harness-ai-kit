# work-sc-software-copyright-writer — Usage

## Overview
软著申请材料撰写技能：产出软件说明书（≥5000字）+ 源程序示例（≥2000行），内置软著审查专家自查。与 work-sc-patent-specification-writer 同簇。仅产出材料，不办理登记。

## When to use
- 为软件项目准备软著登记材料。
- 已有代码库，需提炼合规说明书与源码示例。

## 可直接复制的中文 Prompt

```text
用 work-sc-software-copyright-writer 生成软著材料：
- 软件名称：<名称>  类型：<平台/工具/系统>  版本：<Vx.y>  开发单位：<单位>
- 核心功能模块：<列举，或基于代码库分析>
- 技术架构：<如 Java+SpringBoot / Python>  应用场景：<场景>  创新点：<如有>
请产出：①软件说明书（六章节，≥5000字，实质内容）②源程序示例（≥2000行，体现业务逻辑）
③软著审查专家自查（结构/字数/表述/合规/技术描述/源码质量），并按意见修订。
要求：开发者视角、正式技术语言，避免"AI/智能生成"等词，不含敏感信息。
```
