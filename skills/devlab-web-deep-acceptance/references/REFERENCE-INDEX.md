## 约定

- 陷阱库追加新条目时沿用五段式结构与分组主题，编号追加前重新取最大号（多会话防撞）。
- 项目专属陷阱（组件库私有行为、业务表权限链等）不进通用库，留在项目侧 `.agents/skills/`。
