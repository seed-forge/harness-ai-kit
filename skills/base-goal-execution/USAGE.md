# base-goal-execution

Goal 驱动执行技能。将计划转化为可追踪、可恢复、有验收标准的闭环执行流程。

自包含规范：内嵌 Goal 定义模板、进度报告格式、错误恢复策略、交付报告模板。

## 可直接复制的中文 Prompt

### 制定计划时

```
请帮我制定一个 [任务描述] 的执行计划。
要求：
1. 按 Goal 驱动执行技能的 Phase 0 格式定义目标和验收标准
2. 任务按依赖拓扑排序
3. 每个任务有明确的验收标准
```

### 执行已有计划时

```
请按照 Goal 驱动执行技能执行以下计划：
计划文件路径：{path_to_plan.md}
请从 Phase 1 前置检查开始，逐步执行。
```

### 恢复中断的任务时

```
请继续上次的任务。
计划文件路径：{path_to_plan.md}
请检查已完成的状态，从断点继续执行。
```

## 何时自动激活

- AI 通过 CreatePlan 工具生成计划时
- 用户说"执行计划"、"开始做"、"按照计划来"
- 用户说"继续上次的"、"恢复执行"
- 任何涉及 3 个以上步骤的工程任务
